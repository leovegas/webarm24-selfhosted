# Contributing

Thanks for helping improve the install kit.

- **Documentation fixes and `webarmctl` improvements** are welcome as pull requests. This repository is published from WebArm24's internal repository at each release. We port accepted changes there, so your PR may be closed with a note naming the release that contains it.
- **Bugs:** use the issue templates, and include `./webarmctl doctor --json` output.
- **Feature requests for the application:** open a Discussion or an issue labelled `feature`.
- **Never include secrets:** no license keys, `.env`, registry passwords or unredacted logs.

By contributing you agree that your contribution is licensed under the MIT License of this repository.
